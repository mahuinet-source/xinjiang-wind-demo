Compare different visualization schemes for meteorological data

🎨 Scheme A: Contour Fill

Uses contour lines with color-filled regions. Iso-lines labeled with exact values. Best for scientific publications.

●●● Scheme B: Scatter Points

Each grid point as a circle. Size and color represent wind speed. Good for showing data distribution patterns.

⬡ Scheme C: Hexbin Grid

Aggregates data into hexagonal bins. Each hex shows average wind speed. Modern cartographic style.

Data Source: ICON Weather Model (~7km) | Grid Resolution: 30km | Generated by Claw-KnowledgeMaster
