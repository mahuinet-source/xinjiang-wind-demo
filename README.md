# Xinjiang Wind Speed Visualization

Interactive wind speed maps for Xinjiang region using ICON model data.

## Maps

- [xinjiang_wind_viridis.html](xinjiang_wind_viridis.html) - Viridis color scheme (recommended)
- [xinjiang_wind_map_final.html](xinjiang_wind_map_final.html) - Full Xinjiang map with terrain
- [index.html](index.html) - Main demo page

## Features

- Interactive heatmap overlay on satellite/terrain maps
- Multiple base layer switching (Satellite, Topography, Light)
- City markers for major Xinjiang locations
- Wind speed scale in m/s

## Data Sources

- Weather Model: ICON (~7km resolution)
- Grid: ~15km spacing
- Coverage: 35-50°N, 73-97°E

## Usage

Open any HTML file in a browser to view the interactive map.
