## VAPOR Usage

1. Download VAPOR: https://vapor.ucar.edu/content/downloads
2. File → Import → 2D/3D NetCDF
3. Select `xinjiang_wind.nc`
4. Variables: `wind_speed`, `u`, `v`
5. Use Renderers → Mesh renderer for contours
6. Use Flow renderer for wind vectors

## ParaView Usage

1. File → Open → select `.vtr` file
2. Apply filters:
   - **Contour**: iso-surfaces
   - **Slice**: 2D cross-sections  
   - **Glyph**: wind vectors
   - **Warp By Scalar**: 3D visualization
