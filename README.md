## Data Specifications

- **Weather Model**: ICON (~7km resolution)
- **Coverage**: Xinjiang Region (35-50°N, 73-97°E)
- **Grid Resolution**: ~30km
- **Variables**: wind_speed, u_velocity, v_velocity

## ParaView Usage

1. Download ParaView: https://www.paraview.org/download/
2. File → Open → select `.vtr` file
3. Apply filters:
   - **Contour**: Create iso-surfaces
   - **Slice**: 2D cross-sections
   - **Glyph**: Wind vectors
   - **Warp By Vector**: 3D visualization
